Node 24.19.0, TypeScript 5.9.3, React 19.2.0, FFmpeg/FFprobe 7.1.
TypeScript check and Vite production build passed.
12 real backend/media checks passed. Five Chromium checks passed.

The media checks launch real local servers and FFmpeg, inspect and decode the
output, compare the requested source time with the result, test concurrent
idempotent requests, force a process interruption and check recovered jobs.
The browser uploads a clip, exports it, advances actual H.264/AAC playback,
checks visible errors, reload persistence and narrow-screen overflow.

The source is an authored procedural pendulum clip with synthesized audio.
No generation provider, cloud worker or external API is used. The demo has
one local worker and SQLite, not a distributed production scheduler.

The script outputs detailed results to evidence/results.json and
evidence/browser-results.json. Runtime databases and input/output directories
are local test artifacts and excluded from version control. All test servers
were stopped after the verification run.

Power-loss behavior, hostile-media sandboxing, Safari/Firefox, mobile hardware
and production scaling were not verified. Treat imported files as trusted
test inputs. See README.md for the precise local limits.
